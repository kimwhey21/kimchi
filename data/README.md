# data/

평일 예약 실행(GitHub Actions)이 수집한 시세를 `price_<market>_<거래일>.json`으로
남기는 곳입니다. 조사·집필을 맡는 클라우드 루틴이 이 파일을 읽어 원고를 씁니다.

루틴 샌드박스는 네이버·야후·KRX로 나가는 요청이 네트워크 정책에 막혀 있어
(2026-09-02 실측: CONNECT 403) 직접 시세를 받을 수 없습니다. 반면 Actions
러너에서는 정상적으로 받아지고, 루틴의 WebSearch는 막혀 있지 않습니다. 그래서
**시세 수집은 Actions가, 조사·집필은 루틴이** 맡도록 나눴습니다.
